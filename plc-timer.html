Timer Descriptions & Logic

  • TON (On-Delay Timer): When input turns ON, the timer starts. Output turns ON after the preset time elapses while input remains ON. Output turns OFF immediately when input turns OFF.
  • TOF (Off-Delay Timer): Output is ON when input is ON. When input turns OFF, the timer starts. Output remains ON for the preset duration, then turns OFF.
  • RTO (Retentive Timer): Accumulates time while input is ON. Output turns ON when accumulated time reaches the preset. Time is retained (paused) when input is OFF. Must be manually reset.
  • TP (Pulse Timer): When triggered by a rising edge on the input, the timer starts. Output turns ON immediately and stays ON for the preset duration, regardless of subsequent input changes. Then output turns OFF.
